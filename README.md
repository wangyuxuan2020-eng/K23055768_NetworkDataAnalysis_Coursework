## Repository contents
This repository contains the code and supporting files for the Network Data Analysis coursework submission.

### Main files
- `part1.py` — Part 1 analysis of Wikidata editor networks
- `part2.py` — Part 2 analysis of the Leeds road network and road accidents
- `requirements.txt` — Python package dependencies
- `README.md` — repository guide

### Folders
- `data/` — input data files used by the scripts
- `outputs/` — figures and output files generated by the scripts

## Data
This coursework uses two main data sources:

### Part 1
Wikidata Talk page CSV files provided in the coursework dataset pack.

These files should be placed in:

`data/part1/`

### Part 2
Road traffic accident data for Leeds from the official source listed in the coursework instructions.

These files should be placed in:

`data/part2/`

The road network is downloaded from OpenStreetMap through OSMnx in the code, so it does not need to be stored manually in the repository beforehand.
